# O que deve ser feito no sistema de vendas

O sistemas de vendas e gerenciamento de estoque deve ser desenvolvido para que a equipe da logistica possa ter controle sobre os produtos vendidos e em estoque.
É essencial que o sistema esteja integrado ao site de vendas para que os produtos vendidos sejam registrados automaticamente no sistema.
O desenvolvimento de back-end e banco de dados do e-commerce devem ser feitos de forma que possibilite a integração com o sistema de vendas e gerenciamento de estoque.
