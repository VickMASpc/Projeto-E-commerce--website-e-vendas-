# O que é o sistema de analise de vendas

O sistema de análise é a plataforma dedicada á equipe de vendas, onde será possível visualisar em gráficos e tabelas as vendas realizadas, o estoque de produtos e as tendências de vendas.

# O que deve ser feito no sistema de análise

O sistema de análise deve ser desenvolvido para que a equipe de vendas possa ter controle sobre os produtos vendidos e em estoque.
É essencial que o sistema esteja integrado ao sistema de vendas e gerenciamento de estoque para que os produtos vendidos sejam registrados automaticamente no sistema.
O desenvolvimento de back-end e banco de dados do sistema de análise devem ser feitos de forma que possibilite a integração com o sistema de vendas e gerenciamento de estoque.
