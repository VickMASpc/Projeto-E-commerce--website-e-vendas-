# O que é o e-commerce

O e-commerce é a plataforma de vendas online da empresa.

# O que deve ser feito no e-commerce

O e-commerce deve ser desenvolvido para que os clientes possam comprar produtos da empresa.
É essencial que o e-commerce esteja integrado ao sistema de vendas e gerenciamento de estoque para que os produtos vendidos sejam registrados automaticamente no sistema.
O desenvolvimento de back-end e banco de dados do e-commerce devem ser feitos de forma que possibilite a integração com o sistema de vendas e gerenciamento de estoque.
O e-commerce deve ser responsivo e otimizado para dispositivos móveis.
